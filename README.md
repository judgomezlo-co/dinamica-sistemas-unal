# dinamica-sistemas-unal
Repositorio oficial con los modelos de simulación, diagramas causales y proyectos desarrollados para la asignatura de Dinámica de Sistemas.

## 📂 Estructura PROPUESTA del Repositorio

Para mantener el orden y evitar conflictos de control de versiones entre los compañeros de la materia, todo el trabajo práctico se centralizará en la carpeta principal `proyectos/`. 

**Cada estudiante debe crear y trabajar únicamente dentro de su propia carpeta personal** ubicada dentro de este directorio.

La estructura del árbol del repositorio debe mantenerse de la siguiente manera:

```text
dinamica-sistemas/
├── proyectos/
│   ├── juan_gomez/                  # Carpeta personal del estudiante
│   │   ├── proyecto_1/              # Carpeta específica para la entrega 1
│   │   │   ├── documento.mdl        # Documentacion
│   │   │   ├── diagramas/           # Imágenes de diagramas causales y de Forrester
│   │   │   ├── scripts/             # (Opcional) Scripts en el lenguaje que cada uno prefiera
│   │   │   └── reporte_analisis.pdf # Reporte de resultados y conclusiones
│   │   └── proyecto_2/
│   │       └── ...
│   ├── nombre_estudiante_2/        # Carpeta personal de otro estudiante
│   │   ├── proyecto_1/
│   │   └── ...
├── .gitignore
└── README.md
